# Google Services Integration Guide

Every Google Cloud, Firebase, Maps, and Gemini integration in CleanBreath is mapped below with its exact code location, architectural rationale, and verification check.

| Google Service | Where in Code | Why Chosen | How to Verify It Is Running |
| :--- | :--- | :--- | :--- |
| **Gemini API (`@google/genai`, `gemini-4-hydrogen`)** | `src/server/services/geminiClient.ts`, `planService.ts`, `chatService.ts`, `communityService.ts` | Low-latency Flash-tier reasoning with native `responseSchema` structured JSON (`planService`, `communityService`) and token streaming + `abortSignal` cancellation (`chatService`). | Call `POST /api/plan` or `POST /api/chat` with `GEMINI_API_KEY` set; response returns `"isFallback": false` (plans) or streamed `data: {"type":"chunk"}` events (chat). |
| **Vertex AI (`GOOGLE_GENAI_USE_VERTEXAI=true`)** | `src/server/services/geminiClient.ts` (`getGeminiClient` Vertex branch), `src/server/config/env.ts` | Passwordless IAM/Workload Identity authentication (`roles/aiplatform.user`) and regional data residency (`asia-south1`) on Cloud Run without changing schemas or routes. | Set `GOOGLE_GENAI_USE_VERTEXAI=true` + `GOOGLE_CLOUD_PROJECT`; verify `getGeminiClient` initializes Vertex mode and plans return `"isFallback": false`. |
| **Google Maps Air Quality & Geocoding APIs** | `src/server/services/aqiService.ts` (`GMP_ATTRIBUTION_HEADER`), `src/services/quotaEvents.ts` | Authoritative hyper-local US-EPA/Universal AQI, `pm25`/`pm10`/`no2`/`o3` concentrations, and 24-hour hourly forecast with automatic Open-Meteo failover on `429` quota exhaustion. | Call `GET /api/aqi?city=New+Delhi&locality=Rohini` with `GOOGLE_MAPS_API_KEY`; response `"source"` equals `"Google Maps Air Quality API"`. |
| **Firebase Auth & Cloud Firestore** | `src/services/firebase.ts`, `firebase-applet-config.json`, `firestore.rules`, `firebase-blueprint.json` | Instant frictionless Anonymous Guest or Google Sign-In for saving household profiles, daily plans, and community checklists with hardened owner-only security rules. | Sign in on Dashboard/Settings, save a plan, and verify document creation under `users/{uid}/plans/{planId}`; run `npx eslint firestore.rules`. |
| **Firebase App Check (Optional Hardening)** | `src/services/firebase.ts` (`ReCaptchaEnterpriseProvider`), `src/services/apiClient.ts` (`X-Firebase-AppCheck`), `src/server/middleware/appCheck.ts` | Protects `/api/plan` and `/api/chat` Gemini quotas against scripted abuse by verifying RS256 App Check JWTs against Google's JWKS endpoint. | Enable `FIREBASE_APP_CHECK_ENABLED=true` + `FIREBASE_PROJECT_NUMBER`; unauthenticated requests to `/api/plan` return `401`, while signed client tokens pass. |
| **Google Cloud Logging & Cloud Trace** | `src/server/utils/logger.ts` (`buildLogRecord`, `formatCloudTrace`, `createRequestLogger`) | Structured JSON logs (`severity`, `message`, `httpRequest`, `logging.googleapis.com/trace`) parsed natively by Cloud Run Log Explorer without PII or keys. | In `NODE_ENV=production`, inspect stdout/stderr JSON entries on `/api/*` requests for `httpRequest.latency` and trace correlation. |
| **Google Cloud Run & Secret Manager** | `Dockerfile`, `deploy.sh`, `.github/workflows/ci.yml` | Serverless non-root Node 22 container (`node dist-server/server.js`), scale-to-zero between smog episodes, SSE streaming support, and Secret Manager key injection. | Run `./deploy.sh` and confirm `curl -sSf "$SERVICE_URL/api/health"` returns `{"status":"ok"}`. |
| **Google AI Studio & Stitch** | `docs/design/stitch-onboarding.html`, `docs/PROMPTS.md` | Rapid `responseSchema` validation and 6-screen WCAG 2.2 AA UI layout prototyping before modularizing into React/Tailwind components. | Inspect `docs/design/stitch-onboarding.html` and matching views in `src/components/`. |
